# Berserk VPN Bot v5.4.2

ربات تلگرام فروش و توزیع ساب‌لینک آماده VPN با پنل مدیریت تلگرامی.

## نصب سریع روی Railway

متغیرهای محیطی لازم:

```env
BOT_TOKEN=توکن ربات از BotFather
ADMIN_ID=آیدی عددی ادمین
ADMIN_COMMAND=دستور مخفی پنل مدیریت
DB_PATH=/data/berserk.db
BROADCAST_DELAY=0.08
```

اگر Volume ندارید، برای تست موقت می‌توانید بگذارید:

```env
DB_PATH=berserk.db
```

برای استفاده دائمی، بهتر است Volume متصل باشد و مسیر دیتابیس روی `/data/berserk.db` تنظیم شود.

## قابلیت‌های اصلی

- فروش ساب‌لینک آماده از استخر لینک‌ها
- هر لینک فقط یک بار به یک کاربر اختصاص داده می‌شود
- خرید ۱ تا ۴ عدد
- خرید عمده به‌صورت درخواست/تیکت
- کیف پول و کارت به کارت با تایید دستی ادمین
- تشخیص رسید تکراری
- QR Code برای هر لینک
- پنل مدیریت داخل تلگرام
- بک‌آپ و Restore دیتابیس
- رفرال با پرداخت پاداش فقط بعد از اولین خرید واقعی زیرمجموعه
- تیکت پشتیبانی
- پیام همگانی حرفه‌ای
- جزئیات کامل کاربران

## پیام همگانی

از مسیر:

```txt
مدیریت → پیام همگانی
```

قابل ارسال است به گروه‌های هدف مثل:

- همه کاربران غیر بن‌شده
- خریداران
- بدون خرید
- دارای سرویس
- بدون سرویس
- فعال ۷ روز اخیر
- غیرفعال ۷ روز اخیر
- موجودی مثبت
- موجودی کمتر از قیمت پلن
- کاربران رفرالی
- کاربرانی که زیرمجموعه دارند

نوع پیام:

- متن
- عکس + کپشن
- فایل/Document + کپشن

قبل از ارسال، پیش‌نمایش و تعداد گیرنده نمایش داده می‌شود.

## جزئیات کاربران

از مسیر:

```txt
مدیریت → کاربران → جزئیات کاربر
```

نمایش داده می‌شود:

- مشخصات کاربر
- موجودی کیف پول
- وضعیت بن
- خریدها
- سرویس‌های تحویل‌شده
- تاریخ خرید/تحویل
- شارژهای کیف پول
- تراکنش‌های کیف پول
- رفرال‌ها
- تیکت‌ها
- ارسال مجدد لینک و QR سرویس

## نکته مهم

این ربات API پنل VPN ندارد. بنابراین مصرف واقعی، تاریخ اولین اتصال، حجم مصرف‌شده واقعی و وضعیت آنلاین کانفیگ قابل تشخیص نیست. اطلاعات سرویس‌ها بر اساس تاریخ فروش/تحویل لینک ذخیره می‌شود.


## v5.4.3

این نسخه رفتار پنل مدیریت را تمیزتر می‌کند:
- بازگشت به پنل مدیریت پیام‌های تکراری نمی‌سازد.

- دکمه‌های قدیمی حذف یا غیرفعال می‌شوند تا قابل اسپم نباشند.
